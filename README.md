# Class Code Showcase

**Site:** https://kay37.github.io/class-showcase/

Read classmates' IntelliJ projects in the browser: no downloading, no opening IntelliJ, no screen sharing.

## Add your projects

Nobody shows up until they choose to.

1. Open https://kay37.github.io/class-showcase/#/add-me
2. Type your GitHub username and tick the projects you want to show.
3. Click **Continue to GitHub**, then **Create**.

You show up within a few minutes. Do it again any time to change your picks; your newest one counts.
To take everything down, close your "Add me" issue in this repo.

## Comments

Every project page has a comments box at the bottom. Sign in with GitHub to leave one.
Please keep feedback kind and specific.

## Good to know

- Only public repos can be shown.
- If the site says GitHub is limiting requests, wait a few minutes and try again.
